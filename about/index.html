我在这里记录三件事：正在做的运营、正在用的自动化，以及读过的书。它们大多来自具体问题，而不是阅读清单。

现在在做什么

  • 跨境电商：关键词、Listing、广告与复盘。把每个环节拆开看，找出可以复用的部分。
  • 自动化：用脚本和 RPA 接管重复的点击、录入与对账，把时间留给判断。
  • 阅读：微信读书的长期用户。书架上的书总比读完的多，所以单独做了一个页面来管理。

这个站点写什么

三类内容：

  1. 运营笔记：跨境电商的具体问题、操作步骤与复盘，不写空泛的方法论。
  2. 自动化实践：RPA、Excel、脚本。解决一个具体问题，就记一篇。
  3. 阅读记录：读过的书、划过的线，以及它们和工作之间的关系。

不写日更，不写「三天起号」，也不做课程。这里更像一个持续更新的工作台，而不是一个媒体。

关于「阅读」页

阅读页的数据来自微信读书：书架与历史记录由脚本同步成 JSON，构建时由 Hugo 读入，再按在读、已读、想读、准备读和历史阅读分类。没有数据库，也不依赖第三方接口，所以加载很快，也不会因为某个服务下线而消失。

这个站点怎么搭的

Hugo + Stack 主题，托管在 GitHub Pages。内容只有一份，通过 Hugo 的环境配置保留了两套主题；样式、模板与阅读页都是在这个基础上改的，没有换主题。
